This repository contains some sample Python code files used during my MPhil research.

The research focused on detecting denial-of-sleep attacks in IoT networks using machine learning techniques, based on power-related operating-state measurements collected through ContikiOS in COOJA simulations.

The sample notebooks include implementations of machine learning models, data preprocessing, hyperparameter optimisation using Optuna, and model performance evaluation.

These files represent selected parts of the research implementation rather than the complete experimental framework.

Related Publication:

Dissanayake, I., Welhenge, A., & Weerasinghe, H. D. (2025). A Machine Learning Approach to Detect Denial of Sleep Attacks in Internet of Things (IoT). IoT, 6(4), Article 71.

https://doi.org/10.3390/iot6040071

Note: The original experimental dataset and simulation files are not included in this repository. The notebooks are shared as samples of the code used during the research and may require the original dataset and environment-specific adjustments to execute.
